## Implementation Note

The first implementation pass stayed in the deterministic scripts/CI surface.
`scripts/ci/wasm-tcg-coverage-gate.mjs` previously judged only the latest
hot-block summary. That is useful for the end-of-run state, but it can lose an
opcode that was visible in an earlier retained top-N sample and later fell
below the cutoff. The patch adds a `--scope latest|histogram` option and keeps
`latest` as the default. Histogram mode walks all retained summaries and builds
a max-per-op opcode histogram. This matters because the QEMU hot-block opcode
counts are cumulative; summing summaries would inflate evidence, while taking
the maximum preserves earlier observed unsupported shapes without double
counting repeated samples.

The focused test was extended to cover the new histogram behavior. The first
test run failed because I expected `ld`, `st`, and `mb` to remain unsupported
under the deterministic profile, but that profile already includes them. I
corrected the assertion so the histogram gate only treats `call` and the
new synthetic `mul` fixture op as unsupported in that path. After the
correction, `node --check` for the gate and test, the test itself, and scoped
`git diff --check` all passed.

`PLAN.md` now has a single checked R4d-e item for this scripts/CI discipline.
It records the accepted behavior, test commands, and the fact that no browser
run, artifact build, speed claim, BusDK work, or Bus Engine OS proof was run
